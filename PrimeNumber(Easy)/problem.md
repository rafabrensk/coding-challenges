# Prime Number

Given an integer `n`, determine whether it is a prime number.

A prime number is a positive integer greater than 1 that has exactly two positive divisors: `1` and itself.

**Example 1:**

> **Input:** n = 7  
> **Output:** true  
> **Explanation:** 7 is divisible only by 1 and 7, so it is a prime number.

**Example 2:**

> **Input:** n = 10  
> **Output:** false  
> **Explanation:** 10 is divisible by 1, 2, 5, and 10, so it is not a prime number.

**Example 3:**

> **Input:** n = 1  
> **Output:** false  
> **Explanation:** 1 has only one positive divisor, so it is not a prime number.

**Constraints:**

> **1 <= n <= 2<sup>31</sup> - 1**
