# Fibonacci Sequence

Given an integer `n`, print the first `n` terms of the Fibonacci sequence, starting from `0`.

The Fibonacci sequence is defined as:

`0, 1, 1, 2, 3, 5, 8, 13, ...`

Each term after the first two is calculated by adding the two previous terms.

**Example 1:**

> **Input:** n = 5  
> **Output:** 0 1 1 2 3  
> **Explanation:** The first 5 terms of the Fibonacci sequence are 0, 1, 1, 2, and 3.

**Example 2:**

> **Input:** n = 8  
> **Output:** 0 1 1 2 3 5 8 13  
> **Explanation:** The first 8 terms of the Fibonacci sequence are 0, 1, 1, 2, 3, 5, 8, and 13.

**Example 3:**

> **Input:** n = 1  
> **Output:** 0  
> **Explanation:** The sequence starts with 0, so the first term is 0.

**Constraints:**

> **0 < n <= 30**
