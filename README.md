# Coding Challenges

A collection of programming challenges and their solutions, organized by problem.

Each challenge has its own folder containing:

* A `.md` file with the **problem description** and the **logic behind the solution**.
* One or more solution files, written in **different programming languages**.

## Structure

```text
coding-challenges/
├── challenge-01/
│   ├── problem.md
│   ├── solution.py
│   ├── solution.cpp
│   └── solution.c
│
├── challenge-02/
│   ├── problem.md
│   └── solution.py
│
└── ...
```

The goal is to practice **problem solving, algorithms, and different programming languages** while keeping the solutions organized and easy to revisit.
